Aplikasi web modern jarang berdiri sendiri. Web perlu mengambil data dari server backend atau API pihak ketiga secara asinkron tanpa memblokir antarmuka pengguna (*non-blocking*).

---

## 1. Memahami Konsep Asynchronous & Event Loop

Secara alami, JavaScript adalah bahasa *single-threaded* (menjalankan satu instruksi pada satu waktu). Untuk menangani operasi lambat seperti *HTTP Request* atau *Timer*, browser menggunakan model **Asynchronous Event Loop**:

* **Synchronous (Blocking)**: Kode baris ke-2 harus menunggu baris ke-1 selesai. Jika baris ke-1 memuat file 10 detik, layar akan *freeze*.
* **Asynchronous (Non-Blocking)**: Operasi berat didelegasikan ke latar belakang browser. Ketika data selesai diunduh, fungsi panggilan balik (*callback*) atau `Promise` akan dijalankan.

---

## 2. Pola Sintaks Modern: `async / await` & `fetch()`

Sintaks `async/await` diperkenalkan di ES2017 untuk membuat penulisan kode asinkron tampak bersih dan mudah dibaca layaknya kode sekuensial sinkron.

```javascript
async function loadUserData(userId) {
  try {
    // 1. Kirim HTTP GET request
    const response = await fetch(`https://api.example.com/users/${userId}`);
    
    // 2. Periksa status HTTP (200-299)
    if (!response.ok) {
      throw new Error(`HTTP Error! Status: ${response.status}`);
    }
    
    // 3. Konversi response body ke objek JSON
    const data = await response.json();
    console.log("Data berhasil diterima:", data);
    return data;
  } catch (error) {
    console.error("Gagal mengambil data:", error);
  }
}
```

## 4. Menyimpan Status dengan `localStorage`

Agar data tidak hilang saat pengguna merefresh browser, gunakan `localStorage`:

```javascript
// Menyimpan data
localStorage.setItem('theme', 'dark');
localStorage.setItem('user', JSON.stringify({ name: 'Wahyu', score: 100 }));

// Mengambil data
const theme = localStorage.getItem('theme');
const user = JSON.parse(localStorage.getItem('user'));
```
