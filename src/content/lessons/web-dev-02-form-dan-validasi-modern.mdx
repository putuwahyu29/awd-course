Formulir (*web form*) adalah pintu utama interaksi antara pengguna dan aplikasi web. Pada tugas praktik ini, Anda akan mempelajari tipe input HTML5 terbaru, atribut validasi bawaan (*Constraint Validation API*), serta merancang formulir yang aman dan ramah pengguna.

---

## 1. Tipe Input & Atribut Validasi Bawaan HTML5

HTML5 menyediakan mekanisme validasi di sisi peramban tanpa perlu menuliskan kode JavaScript yang panjang:

* **Tipe Input Khusus**:
  * `type="email"`: Memastikan format email valid (memiliki simbol `@` dan domain).
  * `type="password"`: Menyembunyikan karakter input demi keamanan.
  * `type="tel"` & `type="number"`: Menampilkan keyboard angka pada perangkat seluler.
  * `type="date"`: Menampilkan kalender *date-picker* bawaan sistem operasi.
* **Atribut Validasi Inti**:
  * `required`: Field wajib diisi sebelum form dapat dikirim (*submit*).
  * `minlength` & `maxlength`: Membatasi jumlah karakter minimum/maksimum.
  * `pattern="[A-Za-z0-9_]{5,}"`: Validasi berbasis Regex (*Regular Expression*).
  * `autocomplete="username"` / `autocomplete="current-password"`: Membantu manajer kata sandi browser mengisi data otomatis.

<Callout type="tip" title="Labeling Aksesibel">
  Jangan pernah menggantikan `<label>` dengan sekadar atribut `placeholder`. Placeholder akan hilang saat pengguna mulai mengetik, sedangkan tag `<label for="idInput">` memberikan konteks permanen bagi pengguna dan alat bantu disabilitas.
</Callout>

function showError(input, message) {
