## 1. Anatomi CSS Box Model

Setiap elemen HTML yang dirender di layar diperlakukan sebagai sebuah kotak persegi panjang yang terdiri dari 4 lapisan:

```
+-------------------------------------------------+
|                    MARGIN                       |
|   +-----------------------------------------+   |
|   |                 BORDER                  |   |
|   |   +---------------------------------+   |   |
|   |   |             PADDING             |   |   |
|   |   |   +-------------------------+   |   |   |
|   |   |   |         CONTENT         |   |   |   |
|   |   |   |   (width x height)      |   |   |   |
|   |   |   +-------------------------+   |   |   |
|   |   +---------------------------------+   |   |
|   +-----------------------------------------+   |
+-------------------------------------------------+
```

1. **Content**: Area teks, gambar, atau elemen anak sebenarnya.
2. **Padding**: Ruang kosong transparan di antara konten dan garis batas (border).
3. **Border**: Garis tepi pembatas yang membungkus padding dan konten.
4. **Margin**: Jarak pemisah antara elemen ini dengan elemen luar lainnya.

<Callout type="tip" title="Aturan Emas: box-sizing: border-box">
  Secara bawaan (*content-box*), menambahkan `padding: 20px` pada elemen selebar `width: 200px` akan membuat total lebarnya menjadi `240px`. Dengan menerapkan `box-sizing: border-box`, padding dan border akan dihitung di dalam dimensi yang Anda tetapkan sehingga tata letak tidak mudah pecah.
</Callout>

```css
/* Pasang reset ini di baris pertama CSS global Anda */
*, *::before, *::after {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}
```

## 2. CSS Custom Properties (Variabel CSS) & Desain Sistem

Variabel CSS memungkinkan Anda menyimpan nilai warna, ukuran font, dan jarak (*spacing*) di satu tempat terpusat (`:root`), sehingga perubahan tema atau palet warna dapat dilakukan dalam hitungan detik.

```css
:root {
  /* Skala Warna Inti */
  --primary: #0284c7;
  --primary-hover: #0369a1;
  --bg-surface: #0f172a;
  --bg-card: #1e293b;
  --text-main: #f8fafc;
  --text-muted: #94a3b8;
  
  /* Token Spacing & Radius */
  --radius-md: 8px;
  --radius-lg: 16px;
  --space-unit: 1rem;
}

/* Penerapan pada Komponen */
.card {
  background-color: var(--bg-card);
  color: var(--text-main);
  border-radius: var(--radius-md);
  padding: var(--space-unit);
}
```

## 4. Selektor CSS Modern

CSS modern kini memiliki selektor canggih yang mempermudah perancangan tata letak tanpa ketergantungan JavaScript:

* `:is(h1, h2, h3)`: Mengelompokkan selektor majemuk secara ringkas.
* `:has(.button-active)`: Selektor "induk" (*parent selector*) yang dapat menata elemen pembungkus jika elemen anak tertentu aktif.
* `:not(:last-child)`: Menerapkan margin ke semua item kecuali item terakhir.

Di pelajaran selanjutnya, kita akan menggabungkan variabel ini untuk membangun tata letak responsif penuh dengan **Flexbox dan CSS Grid**.
