## 1. Anatomi Standar Dokumen HTML5

Setiap dokumen web modern dibangun di atas kerangka standar yang diakui oleh W3C (*World Wide Web Consortium*). Kerangka ini memastikan peramban (browser) merender konten secara konsisten di seluruh sistem operasi.

```html
<!DOCTYPE html>
<html lang="id">
  <head>
    <!-- Pengkodean karakter universal UTF-8 -->
    <meta charset="UTF-8" />
    
    <!-- Pengaturan skala responsif untuk perangkat seluler -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    
    <!-- Informasi metadata SEO & Media Sosial -->
    <meta name="description" content="Portal kursus pemrograman frontend modern." />
    <title>Awd Course | Frontend Mastery</title>
  </head>
  <body>
    <!-- Konten halaman yang dapat dilihat pengguna -->
  </body>
</html>
```

<Callout type="tip" title="Pentingnya Meta Viewport">
  Tag `<meta name="viewport" content="width=device-width, initial-scale=1.0" />` wajib disertakan pada setiap file HTML. Tanpa tag ini, peramban ponsel pintar akan menganggap website berukuran desktop dan mengecilkannya (*zoom-out*), merusak tampilan responsif Anda.
</Callout>

## 2. Mengapa HTML5 Semantik Sangat Penting?

Elemen semantik adalah elemen HTML yang memberikan arti (*meaning*) dan konteks yang jelas bagi manusia, mesin pencari (SEO), dan alat bantu aksesibilitas (*screen reader* bagi tunanetra).

### Perbandingan Elemen Non-Semantik vs Semantik

| Elemen Semantik | Fungsi & Peruntukan | Pengganti Pola Lama |
| :--- | :--- | :--- |
| `<header>` | Memuat logo, identitas situs, atau judul bagian artikel | `<div class="header">` |
| `<nav>` | Membungkus tautan navigasi utama situs | `<div class="menu">` |
| `<main>` | Memuat konten unik dan utama dokumen (hanya 1 per halaman) | `<div id="content">` |
| `<article>` | Konten mandiri yang dapat didistribusikan ulang (misal: postingan blog, produk) | `<div class="post">` |
| `<section>` | Pengelompokan konten tematik yang memiliki judul sub-bagian | `<div class="section">` |
| `<aside>` | Konten pelengkap seperti sidebar, daftar materi terkait, atau kutipan | `<div class="sidebar">` |
| `<footer>` | Catatan kaki, hak cipta, dan informasi kontak situs | `<div id="footer">` |

<Callout type="note" title="Hierarki Heading (h1 s/d h6)">
  Gunakan tepat **satu** `<h1>` pada setiap halaman sebagai judul utama dokumen. Gunakan `<h2>` untuk sub-topik besar, dan `<h3>` untuk rincian di bawah `<h2>`. Hindari melompati tingkat heading (misal dari `<h1>` langsung ke `<h4>`).
</Callout>

## 4. Aksesibilitas (A11y) & Praktik Terbaik

1. **Atribut `alt` pada Gambar**: Selalu sertakan deskripsi bermakna pada tag `<img>` (misal: `alt="Grafik perbandingan performa browser"`).
2. **Keterbacaan Warna**: Pastikan rasio kontras teks terhadap latar belakang memenuhi minimal standar WCAG AA (rasio 4.5:1).
3. **Formulir Terhubung**: Setiap `<input>` harus memiliki pasangan `<label for="inputId">` yang sesuai untuk mempermudah navigasi pembaca layar.

Di materi berikutnya, kita akan mendalami teknik perancangan **Formulir Interaktif dan Validasi Data HTML5 Modern**.
