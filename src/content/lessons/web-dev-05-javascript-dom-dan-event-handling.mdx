HTML memberikan struktur dan CSS memberikan estetika, namun **JavaScript** adalah nyawa yang membuat aplikasi web menjadi hidup, responsif terhadap tindakan pengguna, dan interaktif.

## 1. Konsep Dasar DOM (*Document Object Model*)

Ketika peramban memuat dokumen HTML, peramban menyusun representasi pohon (*tree structure*) dari seluruh elemen di memori. Pohon objek ini disebut **DOM**.

Melalui JavaScript, kita dapat:
1. **Memilih Elemen**: `document.querySelector('.class')` atau `document.querySelectorAll('button')`.
2. **Memodifikasi Teks & Struktur**: `element.textContent`, `element.innerHTML`, `element.appendChild()`.
3. **Mengubah Kelas CSS**: `element.classList.add()`, `element.classList.remove()`, `element.classList.toggle()`.
4. **Merespons Tindakan Pengguna (*Event Listener*)**: `element.addEventListener('click', handlerFunction)`.

---

## 2. Sintaks JavaScript ES6+ Penting

* **Deklarasi Variabel Modern**: Gunakan `const` untuk nilai yang tidak akan di-reassign, dan `let` untuk variabel yang nilainya dapat berubah. Hindari penggunaan `var`.
* **Arrow Functions**: `const hitung = (a, b) => a + b;`
* **Template Literals**: Menggabungkan string dan variabel secara elegan:
  ```javascript
  const nama = "Wahyu";
  console.log(`Halo, nama saya ${nama}!`);
  ```
* **Destructuring**: `const { title, duration } = course;`

## 4. Event Delegation untuk Kinerja Tinggi

Ketika Anda memiliki banyak elemen dinamis (seperti daftar ribuan data), jangan pasang event listener ke setiap item individual. Pasanglah **satu** event listener pada elemen induknya (`taskList`), lalu gunakan `e.target` untuk mendeteksi elemen mana yang diklik. Teknik ini menghemat memori browser secara signifikan.

Di modul selanjutnya, kita akan mempelajari cara menghubungkan antarmuka ini ke server menggunakan **Asynchronous JavaScript dan Fetch API**.
