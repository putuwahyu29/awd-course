Dua teknik tata letak paling esensial dalam web frontend modern adalah **Flexbox (1 Dimensi)** dan **CSS Grid (2 Dimensi)**. Memahami kapan dan bagaimana menggabungkan keduanya akan membuat Anda mampu mendesain antarmuka apa pun dengan cepat dan presisi.

---

## 1. Perbedaan Utama Flexbox vs CSS Grid

| Aspek | CSS Flexbox | CSS Grid |
| :--- | :--- | :--- |
| **Dimensi** | 1 Dimensi (Baris *atau* Kolom) | 2 Dimensi (Baris *dan* Kolom secara simultan) |
| **Pendekatan** | *Content-first* (elemen menentukan ruang) | *Layout-first* (wadah menentukan ruang) |
| **Kasus Penggunaan Ideal** | Menu bar, form tombol berdampingan, badge ikon, perataan tengah | Halaman dashboard, galeri produk, majalah berita, grid kartu dinamis |

---

## 2. Properti Kunci Flexbox

```css
.flex-container {
  display: flex;
  flex-direction: row;          /* row | column | row-reverse */
  justify-content: space-between; /* flex-start | center | space-between | space-around */
  align-items: center;          /* stretch | center | flex-start | flex-end */
  flex-wrap: wrap;              /* nowrap | wrap */
  gap: 1rem;                    /* Jarak antar item tanpa perlu margin anak */
}
```

---

## 3. Properti Kunci CSS Grid & Responsif Otomatis

Keunggulan terbesar CSS Grid adalah kemampuan menyusun kolom responsif otomatis tanpa *media query* kaku menggunakan `repeat(auto-fit, minmax(...))`:

```css
.grid-container {
  display: grid;
  /* Kolom otomatis bertambah/berkurang sesuai lebar layar, minimal 260px */
  grid-template-columns: repeat(auto-fit, minmax(260px, 1fr));
  gap: 1.5rem;
}
```
