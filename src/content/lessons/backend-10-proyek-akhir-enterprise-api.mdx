## 2. Standar Kualitas & Arsitektur yang Wajib Dipenuhi

### A. Struktur Proyek Berlapis (Clean Architecture)
```text
src/
├── config/             # Konfigurasi database, env variables, & redis client
├── controllers/        # HTTP Request & Response handlers
├── middlewares/        # Auth, Role Guard, Zod Validator, Centralized Error Handler
├── routes/             # Pemetaan endpoint & method HTTP
├── services/           # Logika bisnis inti murni (Business Logic)
├── repositories/       # Interaksi database (Prisma / SQL)
├── schemas/            # Definisi validasi input (Zod Schemas)
└── app.js              # Express app initialization
```

### B. Daftar Fitur Wajib (Must-Have Checklist)
- [ ] **Autentikasi & Otorisasi**:
  - Registrasi & Login dengan Password Hashing (Argon2 / Bcrypt).
  - Akses token JWT (15 menit) + Refresh Token di HttpOnly Cookie.
  - Role-Based Access Control (RBAC) pada endpoint sensitif.
- [ ] **Database & Relasi**:
  - Skema PostgreSQL terdefinisi di `schema.prisma` dengan relasi 1:N dan N:M.
  - Migrasi database terdokumentasi dengan `prisma migrate`.
  - Transaksi ACID terisolasi pada operasi multi-tabel (`prisma.$transaction`).
- [ ] **Validasi & Error Handling**:
  - Validasi payload request dengan Zod / Joi.
  - Centralized Error Handling Middleware dengan standar JSON Response Envelope.
- [ ] **Performa & Skalabilitas**:
  - Indeks B-Tree pada kolom foreign key dan kolom pencarian.
  - Caching Redis pada endpoint yang sering dibaca (misal: katalog produk populer).
  - Rate Limiting (misal: `express-rate-limit` atau Redis Token Bucket).
- [ ] **Testing & Dokumentasi**:
  - Pengujian otomatis (Unit Test / Integration Test dengan **Vitest** atau **Jest & Supertest**).
  - Dokumentasi API interaktif dengan **Swagger / OpenAPI** atau Postman Collection.

## 3. Contoh Dockerfile Produksi Multi-Stage

Untuk menjamin aplikasi Anda dapat dijalankan di lingkungan server manapun (AWS, DigitalOcean, VPS Linux, Railway, atau Render), sertakan `Dockerfile` multi-stage:

```dockerfile
# Stage 1: Build & Dependencies
FROM node:22-alpine AS builder
WORKDIR /app
COPY package*.json ./
COPY prisma ./prisma/
RUN npm ci
COPY . .
RUN npx prisma generate
RUN npm run build --if-present

# Stage 2: Production Runner
FROM node:22-alpine AS runner
WORKDIR /app
ENV NODE_ENV=production
COPY package*.json ./
RUN npm ci --only=production
COPY --from=builder /app/prisma ./prisma
COPY --from=builder /app/src ./src

EXPOSE 3000
CMD ["npm", "start"]
```
