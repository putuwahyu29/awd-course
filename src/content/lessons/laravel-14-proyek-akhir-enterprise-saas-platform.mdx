Pada tugas proyek akhir ini, Anda akan merancang dan membangun arsitektur aplikasi **Software as a Service (SaaS)** skala enterprise yang menggabungkan seluruh modul pembelajaran dari tingkat dasar hingga mahir.

---

## 1. Spesifikasi Fitur Utama Proyek Akhir

Platform SaaS yang Anda bangun wajib memiliki arsitektur lengkap berikut:

1. **Lapisan Database & Eloquent**:
   * Skema multi-relasi antara Model `Tenant` (Organisasi), `User` (Pengguna), `Product` (Barang), `Order` (Transaksi Pesanan), dan `OrderItem`.
   * Implementasi *Global Scope* untuk isolasi data antar organisasi (*Multi-Tenancy data isolation*).
2. **Lapisan Panel Admin Reaktif (Filament PHP 3)**:
   * Dasbor metrik real-time: Total Omzet Penjualan Bulanan, Grafik Tren Transaksi, dan Notifikasi Stok Menipis.
   * Tabel Filament dengan export data Excel/CSV dan filtering tanggal interaktif.
3. **Lapisan RESTful API & Keamanan**:
   * Endpoint otentikasi Sanctum untuk mobile/frontend clients.
   * Validasi ketat menggunakan kelas Form Request mandiri.
4. **Background Jobs & Event-Driven**:
   * Event `OrderPlaced` yang men-dispatch `GenerateInvoicePdfJob` ke antrean Redis secara asinkron.
5. **Jaminan Kualitas**:
   * Minimal 5 automated Feature Tests menggunakan Pest PHP dengan status seluruh tes lulus 100% (*Green*).
