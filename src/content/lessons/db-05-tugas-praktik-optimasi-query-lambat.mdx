## 1. Studi Kasus Masalah: Menghitung Top 3 Produk Terlaris per Kategori

Bayangkan Anda memiliki tabel `orders` dan `order_items` dengan 5.000.000 data transaksi.

### Pola Buruk (Correlated Subquery Lambat):
```sql
-- ❌ SANGAT LAMBAT (Mengeksekusi subquery berulang kali untuk setiap baris!)
SELECT * FROM products p
WHERE p.id IN (
  SELECT product_id FROM order_items oi
  WHERE oi.category_id = p.category_id
  ORDER BY quantity DESC LIMIT 3
);
```

### Pola Modern & Cepat (Window Functions & CTE):
```sql
-- ✅ CEPAT & BERSIH (Hanya 1 kali lewatan pemindaian tabel!)
WITH ranked_sales AS (
  SELECT 
    p.category,
    p.title,
    SUM(oi.quantity) AS total_sold,
    ROW_NUMBER() OVER (PARTITION BY p.category ORDER BY SUM(oi.quantity) DESC) AS rank_in_category
  FROM products p
  INNER JOIN order_items oi ON p.id = oi.product_id
  GROUP BY p.id, p.category, p.title
)
SELECT category, title, total_sold, rank_in_category
FROM ranked_sales
WHERE rank_in_category <= 3;
```

  region,
