**Regresi Linier** adalah algoritma supervised learning tertua dan paling fundamental yang digunakan untuk memprediksi nilai kuantitatif kontinu (seperti prediksi harga properti, estimasi pendapatan daerah, atau proyeksi inflasi).

---

## 1. Persamaan Garis Regresi Linier

Regresi linier mencari garis lurus (*line of best fit*) terbaik yang meminimalkan jumlah kuadrat jarak antara titik data aktual dan garis prediksi (*Ordinary Least Squares*):

$$y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \dots + \epsilon$$

* $y$: Variabel Target (Dependen) yang diprediksi.
* $X$: Fitur/Variabel Bebas (Independen).
* $\beta_1$: Koefisien bobot kemiringan garis (*slope*).
* $\beta_0$: Titik potong sumbu Y (*intercept*).

---

## 2. Implementasi dengan Python & Scikit-Learn

```python
import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error, r2_score

# 1. Dataset Simulasi: Luas Bangunan (m2) vs Harga Rumah (Juta Rp)
X = np.array([[36], [45], [60], [72], [90], [120], [150], [200]])
y = np.array([300, 380, 520, 610, 750, 980, 1250, 1700])

# 2. Split Data Latih dan Uji
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=42)

# 3. Inisialisasi & Latih Model
model = LinearRegression()
model.fit(X_train, y_train)

# 4. Prediksi
y_pred = model.predict(X_test)
print("Prediksi Harga:", y_pred)
print("Harga Aktual:", y_test)
```

---

## 3. Metrik Evaluasi Regresi

| Metrik Evaluasi | Penjelasan | Karakteristik |
| :--- | :--- | :--- |
| **MAE (*Mean Absolute Error*)** | Rata-rata selisih absolut antara nilai asli dan prediksi | Tahan terhadap outlier |
| **MSE (*Mean Squared Error*)** | Rata-rata kuadrat selisih kesalahan | Menghukum kesalahan besar secara berat |
| **$R^2$ (*R-Squared*)** | Proporsi varians data yang berhasil dijelaskan oleh model (rentang 0 s/d 1) | Nilai mendekati 1.0 menandakan model sangat akurat |

```python
r2 = r2_score(y_test, y_pred)
mse = mean_squared_error(y_test, y_pred)

print(f"Skor R-Squared: {r2:.4f}")
print(f"Mean Squared Error: {mse:.2f}")
```

<Callout type="tip" title="Interpretasi Koefisien">
  Gunakan `model.coef_` untuk melihat seberapa besar pengaruh setiap kenaikan 1 satuan fitur terhadap nilai target yang diprediksi.
</Callout>
