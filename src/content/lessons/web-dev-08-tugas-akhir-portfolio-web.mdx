## 1. Spesifikasi Persyaratan Proyek Akhir

Website portfolio yang Anda bangun wajib memenuhi rubrik kriteria berikut:

1. **Struktur HTML5 Semantik**: Memiliki `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, dan `<footer>`.
2. **Tata Letak Responsif**: Tampilan harus rapi baik di layar ponsel (360px) maupun layar laptop/desktop (1200px) menggunakan CSS Grid dan Flexbox.
3. **Fitur Pengubah Tema (Dark/Light Mode)**: Menggunakan variabel CSS untuk mengubah warna latar belakang dan teks secara seketika.
4. **Interaktivitas JavaScript**:
   * Filter galeri proyek (misal: tombol "Semua", "Web App", "UI Design").
   * Validasi formulir kontak pesan sebelum pengiriman.
